# Ufanet Pool Reservation API

REST API для управления клиентами и бронированиями бассейна.

## Технологии

- Java 25
- Spring Boot 4.1.2
- Spring Web MVC
- Spring JDBC
- PostgreSQL
- Maven

## Возможности

- Получение списка клиентов и информации о конкретном клиенте
- Создание и обновление клиентов
- Получение доступных временных слотов
- Просмотр бронирований на выбранную дату
- Создание и отмена бронирований
- Проверка рабочего расписания и количества свободных мест

## Структура базы данных

Для работы приложения используется PostgreSQL.

SQL-скрипт создания таблиц и начального расписания находится в `db/schema.sql`.

### Таблицы

**clients**

| Поле | Тип | Описание |
|---|---|---|
| id | BIGINT | Первичный ключ |
| name | VARCHAR(200) | Имя клиента |
| phone | VARCHAR(30) | Телефон |
| email | VARCHAR(255) | Электронная почта |

**reservations**

| Поле | Тип | Описание |
|---|---|---|
| id | BIGINT | Первичный ключ |
| client_id | BIGINT | Ссылка на клиента |
| start_time | TIMESTAMP | Начало бронирования |
| status | VARCHAR(20) | Статус: ACTIVE или CANCELLED |
| cancel_reason | TEXT | Причина отмены |

**working_hours**

| Поле | Тип | Описание |
|---|---|---|
| id | BIGINT | Первичный ключ |
| day_of_week | SMALLINT | День недели: 1–7 |
| open_time | TIME | Время открытия |
| close_time | TIME | Время закрытия |

Начальное расписание: ежедневно с 08:00 до 18:00.

## Установка и запуск

### 1. Создание базы данных

Создайте базу данных PostgreSQL:

```sql
CREATE DATABASE pool_ufanet_db;
```

### 2. Создание таблиц

Выполните SQL-скрипт `db/schema.sql` в базе `pool_ufanet_db`.

Скрипт создаёт таблицы, индексы, ограничения и начальное расписание бассейна.

### 3. Настройка подключения

В файле `src/main/resources/application.yaml` укажите параметры подключения к PostgreSQL.

Пароль задаётся через переменную окружения `DB_PASSWORD`.

Пример для Linux:

```bash
export DB_PASSWORD='your_database_password'
```

### 4. Запуск приложения

Из корневой директории проекта выполните:

```bash
./mvnw spring-boot:run
```

Приложение будет доступно по адресу `http://localhost:8080`.

## API

Базовый путь: `/api/v0/pool`.

### Клиенты

| Метод | Эндпоинт | Описание |
|---|---|---|
| GET | `/clients` | Получить список клиентов |
| GET | `/clients/{id}` | Получить клиента по ID |
| POST | `/clients` | Создать клиента |
| PATCH | `/clients/{id}` | Обновить данные клиента |

Создание клиента — пример запроса:

```json
{
  "name": "Иван Иванов",
  "phone": "+79990000000",
  "email": "ivan@example.com"
}
```

### Временные слоты и бронирования

| Метод | Эндпоинт | Описание |
|---|---|---|
| GET | `/time-slots/available?date=2026-10-26` | Получить доступные слоты на дату |
| GET | `/reservations?date=2026-10-26` | Получить бронирования на дату |
| POST | `/reservations` | Создать бронирование |
| POST | `/reservations/{id}/cancel` | Отменить бронирование |

Создание бронирования — пример запроса:

```json
{
  "clientId": 1,
  "datetime": "2026-10-26T08:00:00"
}
```

Отмена бронирования — пример запроса:

```json
{
  "clientId": 1,
  "reason": "Изменились планы"
}
```

## Правила бронирования

- Продолжительность одного бронирования — один час.
- Бронирование разрешено только в пределах рабочего расписания.
- Максимальное количество активных бронирований на один временной слот — 10.
- При отмене бронирования его статус меняется на `CANCELLED`.
- Отменённые бронирования не учитываются при подсчёте занятых мест.
